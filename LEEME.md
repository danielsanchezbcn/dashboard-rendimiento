# Dashboard de rendimiento — fase 1b

La documentación completa está en `docs/README.md`: cómo publicar la aplicación, dónde quedan los datos, cómo crear y restaurar copias de seguridad y la lista de comprobación de esta fase.

Estructura: `index.html` y `style.css` (página), `src/` (código), `vendor/` (librerías de terceros ya compiladas), `docs/` (documentación) y `desarrollo/` (pruebas; no hace falta para usar la aplicación).

Importante: sube las carpetas completas, no los ficheros sueltos; la aplicación necesita esta estructura para arrancar.
